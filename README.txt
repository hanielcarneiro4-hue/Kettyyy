Na raiz do repositório GitHub Pages, coloque também:

O site usa exatamente esse nome no código.

Fluxo:
01 Entrada
02 Resposta correta
03 Carta interativa
04 Fotos futuras
05 Surpresinha
06 Cartões
07 Suspense -> FIM -> pós-créditos

O pós-créditos é gerado via JavaScript e contém 35 idiomas, além da mensagem final.
