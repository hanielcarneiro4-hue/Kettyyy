Arquivos obrigatórios na raiz do repositório:
  index.html
  style.css
  script.js
  dont-stop-til-you-get-enough.mp3

A música NÃO deve ficar dentro de assets. O código já procura exatamente:
  ./dont-stop-til-you-get-enough.mp3

Não existe vídeo final nesta versão.
O final é totalmente feito em HTML/CSS/JS: suspense “Agora......” → “FIM” → fade → créditos subindo.

Fluxo:
01 Entrada + resposta
02 Verificação
03 Carta interativa
04 Fotos futuras
05 Surpresinha
06 Cartões
07 Suspense + FIM
08 Pós-créditos com “Eu te amo” em vários idiomas

A música começa na transição para o final e a rolagem dos créditos é animada por CSS.

IMPORTANTE:
O arquivo de áudio não é incluído neste pacote. Coloque o arquivo que você possui com o nome exato:
  dont-stop-til-you-get-enough.mp3

No GitHub, ative GitHub Pages apontando para a pasta raiz do repositório.
